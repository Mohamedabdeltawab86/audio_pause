# مقسم ومكرر الصوت

تطبيق بسيط لتقسيم الملفات الصوتية بناءً على فترات الصمت، مع إمكانية تشغيل المقاطع الناتجة وتكرارها.

![صورة للتطبيق (اختياري)](![alt text](image.png)) <!-- استبدل placeholder.png بمسار صورة لواجهة التطبيق إن وجدت -->

## الميزات الرئيسية

*   **تقسيم ذكي:** تقسيم الملفات الصوتية (مثل MP3, WAV, OGG, FLAC, M4A) عند اكتشاف فترات الصمت.
*   **تحكم دقيق:** ضبط حساسية اكتشاف الصمت (عتبة الديسيبل) وأقل مدة للصمت لاعتباره فاصلًا.
*   **تحديد مدة قصوى (اختياري):** إمكانية تقسيم المقاطع الطويلة جدًا حتى لو لم تحتوِ على صمت كافٍ.
*   **مشغل مدمج:** تشغيل المقاطع الصوتية الناتجة بشكل فردي.
*   **تكرار التشغيل:** إعادة تشغيل المقطع المحدد لعدد معين من المرات.
*   **تشغيل تلقائي:** خيار لتشغيل المقطع التالي تلقائياً بعد انتهاء الحالي.
*   **عرض مرئي:** رسم بياني لشكل الموجة الصوتية مع تحديد المقاطع الناتجة.

## كيفية الاستخدام (النسخة الجاهزة EXE لنظام ويندوز)

هذه هي الطريقة الأسهل للمستخدمين على نظام ويندوز:

1.  **تحميل الحزمة:** اذهب إلى صفحة [**الإصدارات (Releases)**](رابط_صفحة_الإصدارات_في_جيت_هاب_هنا) في هذا المستودع.
    <!-- ^^^^^^^^^^^^^^^^^ استبدل "رابط_صفحة_الإصدارات_في_جيت_هاب_هنا" بالرابط الفعلي لصفحة الإصدارات -->
2.  ابحث عن أحدث إصدار (مثلاً `v1.0.0`).
3.  قم بتحميل الملف المضغوط الذي ينتهي بـ `-windows.zip` (مثلاً `AudioSplitterApp-v1.0.0-windows.zip`).
4.  **فك الضغط:** قم بفك ضغط الملف الذي حملته **بالكامل** في مجلد جديد على جهاز الكمبيوتر الخاص بك.
5.  **هام جداً - FFmpeg:** تأكد من أن الملفين `ffmpeg.exe` و `ffprobe.exe` (الموجودين داخل المجلد الذي تم فك ضغطه) **يبقيان في نفس المجلد** بجانب ملف التطبيق الرئيسي (مثلاً `AudioSplitterApp.exe`). يحتاج التطبيق لهذين الملفين لمعالجة معظم صيغ الصوت (مثل MP3 و M4A).
6.  **تشغيل التطبيق:** انقر نقراً مزدوجاً على ملف `.exe` (مثلاً `AudioSplitterApp.exe`) لتشغيل التطبيق.

## كيفية التشغيل من المصدر (للمطورين)

إذا كنت ترغب في تشغيل الكود مباشرة أو تعديله:

1.  **تثبيت المتطلبات:**
    *   تأكد من تثبيت Python 3.7 أو أحدث.
    *   تأكد من تثبيت `git`.
    *   قم بتثبيت **FFmpeg** وإضافته إلى متغيرات بيئة النظام (PATH). يمكن تحميله من [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) أو [BtbN](https://github.com/BtbN/FFmpeg-Builds/releases). (مكتبة `pydub` تعتمد عليه).
2.  **استنساخ المستودع:**
    ```bash
    git clone https://github.com/اسم_المستخدم_الخاص_بك/اسم_المستودع_الخاص_بك.git
    cd اسم_المستودع_الخاص_بك
    ```
    <!-- ^^^^^^^^^^^^^^^^^ استبدل باسم المستخدم واسم المستودع -->
3.  **إنشاء بيئة افتراضية (مستحسن):**
    ```bash
    python -m venv venv
    # On Windows
    .\venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```
4.  **تثبيت المكتبات:**
    ```bash
    pip install -r requirements.txt
    ```
5.  **تشغيل التطبيق:**
    ```bash
    python audio_splitter_app.py
    ```
    <!-- ^^^^^^^^^^^^^^^^^ تأكد من أن اسم الملف صحيح -->

## المكتبات المستخدمة

*   PyQt5 (للواجهة الرسومية)
*   pydub (لتحميل ومعالجة الصوت واكتشاف الصمت)
*   librosa (لتحميل بيانات الصوت الخام وتحليلها)
*   numpy (للعمليات الرقمية على بيانات الصوت)
*   soundfile (لحفظ وقراءة ملفات الصوت المؤقتة WAV)
*   matplotlib (لرسم شكل الموجة الصوتية)
*   pygame (لتشغيل المقاطع الصوتية)
